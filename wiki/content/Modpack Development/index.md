## This section of the wiki explains how to use the included mods as a Modpack Developer (referenced as packdev going forward).
Below is a short explanation of what each chapter in this section is.

### Phoenix Archives: 
A lore codex mod with documentation that will teach you how to create, modify, and write lore entries. 

### Phoenix's Chromatic Codes: 
A custom color codes/effects mod with documentation that will teach you how to make your own
and use them in game.

### Phoenix Chronicles
A questbook mod with documentation that teaches how to make, edit, and customize quests/chapters as well as how to deal with the files.

### Solaris
A map mod with documentation on how to lock down features and how to edit the map's visuals.

### Phoenix Wiki
A theming/ingame wiki library mod with documentation on how to use/edit themes and wiki pages.

### Phoenix Domains
A chunkloading/claiming mod with documentation that teaches how to add claims/chunkloads to a player as well as the api.

### Phoenix Essentials
An essential commands mod with documentation that teaches how to add more homes/change some default values.

### Phoenix Excavate
A veinmine/place mod with documentation that teaches how to add/disable shapes, add new match modes, and changing the default values.

### Phoenix's Fission
A GregTech:Modern Fission addon with documentation that teaches how to add fission components and some general balancing guidelines.

### Phoenix Guilds
A teams mod with documentation that teaches how to use the flag system.

### Phantasia 
A 3d/2d guides mod with documentation that teaches you how to add scenes/guides/edit scripts and how to use the editors.
