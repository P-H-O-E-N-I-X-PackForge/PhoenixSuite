## Why include theming?
One of the **PhoenixSuite's** main focuses is customization. We want all of our mods and systems to be 
seen visually in the style modpack devs, addon devs, players, etc. actually want. 

Some themes are more visually demanding than others, so the default one is a nice and chill green and black.
We wanted to make themes easy to access, share, and edit, so we made them easy to find and added some UIs.

## What will be covered?
In this section we will teach how to set up new themes, how the color picker works, how to open the theme screen, 
what values map to where, where to look for examples in action, where themes are stored, 
and how to use themes in your own mods.

While mods using themes will differ in how they are accessed, they all share the same screen and underlying 
systems so they are consistent. 

If you want to see any more information on themes, be sure to let us know!
